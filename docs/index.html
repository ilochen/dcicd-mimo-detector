Digital communications IC design

K-best MIMO detector

A 3 × 3 receiver estimates three 16-QAM symbols from six real coordinates. Working backwards through an upper triangular channel matrix, the detector ranks candidate paths by accumulated absolute residual and carries a different number of survivors into each layer.

Hardware mapping

Four valid beats load the 21 coefficients of R using a six-word input bus. Each observation then supplies six z coordinates. The history unit subtracts contributions from coordinates already selected. A metric unit adds |history − Rᵢᵢsᵢ| to each path cost. Compare-and-select logic forwards the surviving costs and coordinate histories, while register chains align the observation with the active layer.

The final vector contains three real coordinates followed by their three imaginary counterparts. The output mapper packs the detected symbols into three four-bit fields.

This walkthrough evaluates the search in real-valued arithmetic. The repository includes the SystemVerilog design, a MATLAB reference, timing constraints, and an RTL metric-unit test. Top-level BER and cycle accuracy are separate validation targets.
